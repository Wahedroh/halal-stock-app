# แอปวิเคราะห์และบันทึกการซื้อหุ้นสหรัฐฯ — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** เว็บแอป (PWA) ส่วนตัวของครูวาเฮด สำหรับดูตัวเลขหุ้นสหรัฐฯ บันทึกซื้อขาย/ปันผล ตั้งเป้า 3 แบบ คัดกรองฮาลาล AAOIFI และมีหน้าคู่มือ

**Architecture:** แยกสูตรคำนวณทั้งหมดเป็นฟังก์ชันบริสุทธิ์ใน `src/lib/` (ทดสอบด้วย Vitest) · ชั้นข้อมูลแยกเป็น `finnhub.js` (เบราว์เซอร์เรียก API ตรง + แคช) และ `store.js` (Firestore) · หน้าจอเป็น vanilla JS แบบ hash router หน้าละไฟล์ใน `src/ui/`

**Tech Stack:** Vite 6, vanilla JS (ES modules), Firebase JS SDK v11 (Auth Google + Firestore + Hosting), vite-plugin-pwa, Vitest

**Spec:** `docs/superpowers/specs/2026-11-25-stock-app-design.md`

## Global Constraints

- หน้าจอภาษาไทยทั้งหมด ออกแบบมือถือก่อน (กว้าง 360–430px)
- ข้อมูลราคา: Finnhub แพ็กฟรี `/quote`, `/stock/metric?metric=all`, `/stock/profile2` เท่านั้น
- API key ไม่อยู่ในโค้ด: ครูกรอกในหน้าตั้งค่า เก็บที่ `users/{uid}.settings.finnhubKey`
- Firestore Security Rules: อ่าน/เขียนได้เฉพาะ `request.auth.uid == uid`
- ราคา การซื้อขาย เป้าเงินลงทุนรวม = USD · เป้าปันผล = บาท แปลงด้วยอัตราในตั้งค่า (ค่าเริ่มต้น 34)
- ค่าเริ่มต้นตั้งค่า: ไม้ 1/2/3 = −5%/−12%/−20% · Trailing เริ่มเมื่อกำไร > 15% ขายเมื่อย่อ 12% จากจุดสูงสุด · ป้ายเตือนเมื่อห่างเป้า ≤ 3% · ภาษีหัก ณ ที่จ่าย 15%
- เป้าปันผลตั้งต้น: 40,000 บาท/เดือน หลังภาษี ภายในอายุ 64 · ลงทุนตั้งต้น 10,000 บาท/เดือน
- รายชื่อเฝ้าดูตั้งต้น: NVDA, AAPL, MSFT, GOOGL, AVGO, MU, TSLA, LLY, AMD, XOM, META สถานะฮาลาลเริ่มต้น "ยังไม่ได้ตรวจ"
- เกณฑ์ AAOIFI: หนี้มีดอกเบี้ย/Market Cap < 30% · เงินฝากมีดอกเบี้ย/Market Cap < 30% · รายได้ต้องห้าม < 5% · % ชำระล้าง = % รายได้ต้องห้าม
- ราคาที่แอปเสนอต้องมีข้อความ "คำนวณตามสูตรที่ครูตั้ง" และแก้ได้เสมอ · ตัวเลขฮาลาลต้องแสดงแหล่งที่มาและวันที่กรอก
- แคช: ราคา 60 วินาที · metric/profile 24 ชั่วโมง (localStorage)
- ไม่มี AI, ไม่มีหุ้นไทย, ไม่มี push notification

## Review Focus

1. สัญลักษณ์หุ้นที่ไม่มีจริง: Finnhub ตอบ `c: 0` → แอปต้องแสดง "ไม่พบหุ้นนี้" ไม่ใช่ราคา $0 หรือ % เป็น NaN
2. Finnhub ตอบ 401 (key ผิด) หรือ 429 (เกินโควตา) → แสดงข้อความไทยที่บอกว่าต้องทำอะไร และใช้ราคาในแคชถ้ามี
3. metric บางตัวเป็น `null` (เช่น P/E ของบริษัทขาดทุน) → แสดง "—" ไม่พัง
4. บันทึกขายเกินจำนวนที่ถือ → ปฏิเสธพร้อมข้อความ
5. หารด้วยศูนย์: ยังไม่มีปันผล, 52W High = Low, Market Cap = 0, อัตราปันผลพอร์ต = 0 → ผลเป็น `null` และ UI แสดง "—"
