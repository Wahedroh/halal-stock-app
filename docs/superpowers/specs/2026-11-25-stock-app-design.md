# แอปวิเคราะห์และบันทึกการซื้อหุ้นสหรัฐฯ — แบบร่าง (Design)

วันที่: 25 พ.ย. 2569 · ผู้ใช้: ครูวาเฮด (ใช้คนเดียว)

## 1. ทำไปเพื่ออะไร
ครูอยากได้แอปส่วนตัวไว้วิเคราะห์หุ้นสหรัฐฯ บันทึกการซื้อขาย และตั้งเป้าหมาย คล้ายแอปที่เห็นในสตอรี่ (หน้า AVGO) โดยต้องคัดกรองหุ้นฮาลาลได้ และอยากเรียนรู้วิธีอ่านตัวเลขหุ้นไปด้วย จึงต้องมีคำอธิบายตัวเลขอยู่ในแอป

## 2. เป้าหมาย / สิ่งที่ไม่ทำ / สิ่งที่ถือว่าล้มเหลว
**เป้าหมาย**
- ดูตัวเลขหุ้นแต่ละตัวที่คำนวณให้อัตโนมัติ: ราคา, % เปลี่ยนแปลง, 52W Low/High, ตำแหน่งในช่วง 52W, Drawdown, ระยะห่างจากแนวรับ, P/E
- บันทึกการซื้อ การขาย และปันผลที่ได้รับ แล้วคำนวณต้นทุนเฉลี่ย กำไร/ขาดทุน และมูลค่าพอร์ต
- ตั้งเป้าได้ 3 แบบ: เป้าราคารายตัว, เป้าเงินลงทุนรวม, เป้าผลตอบแทน/ปันผล
- คัดกรองหุ้นฮาลาลตามเกณฑ์ AAOIFI และคำนวณ % ชำระล้าง
- กดดูคำอธิบายภาษาไทยของตัวเลขทุกตัวได้ในแอป (หน้าคู่มือ)

**สิ่งที่ไม่ทำ (v1)**
- บทวิเคราะห์ด้วย AI (Pros/Cons/Bull/Bear)
- หุ้นไทย
- เชื่อมต่อโบรกเกอร์ หรือส่งคำสั่งซื้อขาย
- แจ้งเตือนแบบ push notification

**ถือว่าล้มเหลวถ้า**
- แอปแนะนำให้ซื้อหรือขายเอง ราคาที่แอปเสนอต้องแสดงชัดว่า "คำนวณตามสูตรที่ครูตั้ง" และครูแก้ได้เสมอ
- ตัวเลขฮาลาลแสดงเหมือนข้อมูลจริง แต่ไม่บอกแหล่งที่มาและวันที่กรอก

## 3. ข้อจำกัด
- ข้อมูลราคามาจาก **Finnhub แพ็กฟรี** (ข้อมูลหุ้นสหรัฐฯ, เรียกได้ 60 ครั้ง/นาที) ใช้ `/quote` (ราคา) `/stock/metric` (52W High/Low, P/E) และ `/stock/profile2` (ชื่อบริษัท, Market Cap)
- ข้อมูลฮาลาลครู**กรอกเอง**จากเว็บคัดกรองหุ้น
- ข้อมูลเก็บใน **Firebase** (Firestore + ล็อกอินด้วย Google)
- เบราว์เซอร์เรียก Finnhub โดยตรง ไม่มีตัวกลางฝั่งเซิร์ฟเวอร์ (แบบ A ที่ครูเลือก)
- หน้าจอภาษาไทย ออกแบบสำหรับมือถือก่อน

## 4. แนวทางที่พิจารณา
| แบบ | ข้อดี | ข้อเสีย |
|---|---|---|
| **A. เบราว์เซอร์เรียก API ตรง** ✅ ครูเลือก | ง่าย ฟรี ไม่ต้องผูกบัตร | API key มองเห็นได้ในเบราว์เซอร์ |
| B. มีตัวกลาง Netlify Functions | ซ่อน key ได้ และพักข้อมูลราคา | ต้องดูแลโค้ด 2 ที่ |

## 5. สิ่งที่ครูตัดสินใจแล้ว
- ตลาด: หุ้นสหรัฐฯ
- เป้าหมาย: ทั้ง 3 แบบ
- ฮาลาล: มี และกรอกข้อมูลเอง
- การวิเคราะห์: ตัวเลขคำนวณอัตโนมัติ + ช่องจดบันทึกความเห็นเอง (ไม่ใช้ AI)
- ราคาซื้อ 3 ไม้: แอปเสนอแบบ**ลดเป็นขั้น %** จากราคาปัจจุบัน ไม้ 1 = −5%, ไม้ 2 = −12%, ไม้ 3 = −20% และครูแก้ราคาได้
- ราคาขาย: **TP = 52W High** + **Trailing** (เริ่มทำงานเมื่อกำไรเกิน 15% และขายเมื่อราคาย่อลงจากจุดสูงสุดหลังซื้อ 12%)
- สอนอ่านหุ้น: สอนในแชท + มีหน้าคู่มือในแอป

## 6. สิ่งที่ผมตัดสินใจเอง (ครูแก้ได้)
1. **API key** ไม่เขียนไว้ในโค้ด ครูกรอก key เองในหน้าตั้งค่า แอปเก็บไว้ในข้อมูลบัญชีของครูบน Firestore
2. **สกุลเงิน** ราคา การซื้อขาย และเป้าเงินลงทุนรวมเป็น USD · **เป้าปันผลเป็นบาท** (ครูกำหนด 25 พ.ย.) แอปแปลง USD→บาทด้วยอัตราแลกเปลี่ยนที่ครูกรอก/แก้ได้ในหน้าตั้งค่า
3. **ปันผล** ครูกรอกเองตอนได้รับ (ผมยังไม่ได้ตรวจว่า Finnhub แพ็กฟรีให้ข้อมูลปันผลหรือไม่)
4. **แนวรับ** ใช้ 52W Low แบบเดียวกับในภาพ
5. **% ของไม้ 1–3 และค่า Trailing** ปรับได้ในหน้าตั้งค่า (ค่าเริ่มต้นตามข้อ 5)
6. **การแจ้งเตือน** แสดงป้ายในแอปเมื่อราคาห่างจากไม้ซื้อ, TP หรือจุด Trailing ไม่เกิน 3%
7. **เกณฑ์ฮาลาล AAOIFI** (ฟอร์มให้กรอก หนี้ที่มีดอกเบี้ย, เงินฝาก/หลักทรัพย์ที่มีดอกเบี้ย, % รายได้ต้องห้าม พร้อมแหล่งที่มาและวันที่):
   - หนี้ที่มีดอกเบี้ย ÷ Market Cap < 30%
   - เงินฝากที่มีดอกเบี้ย ÷ Market Cap < 30%
   - รายได้ต้องห้าม < 5% ของรายได้รวม
   - % ชำระล้าง = % รายได้ต้องห้าม คูณกับปันผลที่ได้รับ (Market Cap ใช้ค่าปัจจุบันจาก Finnhub ไม่ใช้ค่าเฉลี่ย 36 เดือน)
8. **ลดการเรียก API** พักราคาไว้ 1 นาที และพัก 52W/P/E ไว้ 1 วัน ในเครื่อง
9. **โฮสต์** บน Firebase Hosting (แบบเดียวกับเว็บ web.app ของครู) และติดตั้งเป็นแอปบนมือถือได้ (PWA)
10. **จุดสูงสุดหลังซื้อ (ใช้กับ Trailing)** แอปบันทึกราคาสูงสุดที่เห็นทุกครั้งที่เปิดแอป ถ้าราคาพุ่งขึ้นแล้วตกลงระหว่างที่ไม่ได้เปิดแอป จุดสูงสุดจะไม่ถูกบันทึก (ข้อจำกัดของแบบ A ที่ไม่มีเซิร์ฟเวอร์คอยเช็กราคา)
11. **สูตรเป้าหมาย** ผลตอบแทน % = (กำไรที่ขายแล้ว + กำไรที่ยังไม่ขาย + ปันผล) ÷ เงินลงทุนรวม · ปันผลต่อปี = ผลรวมปันผลที่บันทึกในปีปฏิทินนั้น

## 6.1 รายชื่อเฝ้าดูตั้งต้น (ครูสั่งเพิ่ม 25 พ.ย.)
เปิดแอปครั้งแรกจะมีหุ้น 11 ตัวนี้ในรายชื่อเฝ้าดู ครูลบหรือเพิ่มเองได้ ไม่ได้จัดอันดับหรือแนะนำ
ที่มา: หุ้น 10 อันดับแรกของกองทุน SPUS (ข้อมูล Schwab ณ 14 ต.ค. 2569) + META ที่อยู่ในอันดับต้นของกองทุน HLAL

NVDA, AAPL, MSFT, GOOGL, AVGO, MU, TSLA, LLY, AMD, XOM, META

- ผ่านเกณฑ์ชารีอะฮ์ของดัชนีที่กองทุนใช้ ซึ่งอาจไม่เหมือน AAOIFI ทุกข้อ
- สถานะฮาลาลเริ่มต้นเป็น **"ยังไม่ได้ตรวจ"** จนกว่าครูจะกรอกข้อมูลในฟอร์มฮาลาล
- กองทุนปรับรายชื่อทุกเดือน รายชื่อนี้จึงเป็นข้อมูล ณ วันที่ทำแบบร่างเท่านั้น

## 6.2 เป้าปันผลตั้งต้น (ครูสั่งเพิ่ม 25 พ.ย.)
- เป้า: ปันผล **40,000 บาท/เดือน** (= 480,000 บาท/ปี) หลังหักภาษี ภายในอายุ 64 · เงินลงทุนตั้งต้น **10,000 บาท/เดือน** ครูแก้ได้ทั้งหมด (ครูสั่ง 25 พ.ย.)
- ความคืบหน้า: ปันผลที่บันทึกจริง (หลังหักภาษี) ในรอบ 12 เดือนล่าสุด ÷ 12 แล้วแปลงเป็นบาท
- เครื่องคำนวณเงินต้นที่ต้องใช้:
  ปันผลก่อนภาษีที่ต้องได้ = เป้าต่อปี ÷ (1 − ภาษีหัก ณ ที่จ่าย)
  เงินต้น = ปันผลก่อนภาษี ÷ อัตราปันผลเฉลี่ยของพอร์ต
  - ภาษีหัก ณ ที่จ่ายค่าเริ่มต้น **15%** (อัตราตามอนุสัญญาภาษีไทย–สหรัฐฯ เมื่อยื่น W-8BEN) แก้ได้ในหน้าตั้งค่า
  - อัตราปันผลของพอร์ต: ถ้ายังไม่มีหุ้นในพอร์ต ให้ครูกรอกเองเพื่อทดลองคำนวณ
  - ยังไม่รวมภาษีเงินได้ฝั่งไทย

## 7. หน้าจอหลัก
```
[พอร์ต]  มูลค่ารวม $x · กำไร/ขาดทุน · แถบเป้าเงินลงทุน
         รายการหุ้นที่ถือ + ป้ายเตือนใกล้ราคาเป้า
[หุ้น]   AVGO $303.27 −3.28%  🟢ฮาลาล
         แถบ 52W (ตำแหน่ง 7%) · Drawdown · แนวรับ · P/E   (ⓘ กดดูคำอธิบาย)
         แผนซื้อ 3 ไม้ (แก้ได้) · TP / Trailing
         ประวัติซื้อขายของตัวนี้ · บันทึกความเห็น
[เป้าหมาย] เงินลงทุนรวม / ผลตอบแทน % / ปันผลต่อปี → แถบความคืบหน้า
[คู่มือ]  คำอธิบายตัวเลขทุกตัว
[ตั้งค่า] API key · % ไม้ 1–3 · Trailing
```

## 8. ส่วนที่ปล่อยให้คนสร้างตัดสินใจ
เลือกเฟรมเวิร์กฝั่งหน้าเว็บ, โครงสร้างคอลเลกชันใน Firestore, Security Rules (ให้อ่าน/เขียนได้เฉพาะเจ้าของข้อมูล), วิธีคำนวณต้นทุนเฉลี่ยเมื่อขายบางส่วน (ใช้ต้นทุนเฉลี่ยถ่วงน้ำหนัก) และดีไซน์หน้าตา
